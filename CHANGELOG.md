## [1.0.0-alpha] - 2026-07-25

### Added

#### Core Navigation
* Navigation History
* Navigation Categories
* Navigation Blocking
* Root Protection
* Navigation Root Reached event

#### Integration
* Bridge-Based Integration
* Legacy Input Manager support
* Unity Input System support
* Custom `BackInputSource` support
* `InitializeSession()` for starting a new navigation session

#### Reference Implementations
* Complete UGUI Demo
* Legacy Input reference implementation
* Unity Input System reference implementation
* Runtime Monitor reference implementation

#### Runtime Diagnostics
* Runtime Monitor for inspecting navigation state during Play Mode

#### Designer Workflows
* Trailback Event Listener
* Inspector-based event callbacks

#### Documentation
* README
* Features Guide
* Handling Scene Changes Guide
* Reference Samples Guide
* Troubleshooting Guide

### Status

First public alpha release.

This release focuses on validating the core navigation framework, integration workflow, documentation, and reference implementations. APIs and sample content may evolve based on community feedback before the first stable release.
